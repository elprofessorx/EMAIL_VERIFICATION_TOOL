# Email Verification Tool

A simple Python script to check if an email address is valid and deliverable using the Abstract API.

## Features

* Check email deliverability
* Check email format
* Check SMTP validity
* Detect email provider
* Check email quality score
* Detect disposable emails
* Colored terminal output

## Installation

Clone the repository:

```bash
https://github.com/elprofessorx/EMAIL_VERIFICATION_TOOL.git
cd EMAIL_VERIFICATION_TOOl
```

Install the required package:

```bash
pip install requests
```

## Usage

Add your API key in the script:

```python
API_KEY = "YOUR_API_KEY"
```

Then run:

```bash
python email_verifier.py
```

Enter the email you want to check when asked.

## Note

You need an Abstract API key to use this tool.

Don't upload your API key to GitHub.
